## 10 Kingdoms
Сайт для руководства и общей информации в разговорно ролевую игру 10 королевств
####
php 8.3, npm 11.6.2

### Установка
```
composer install
php artisan key:generate
php artisan migrate
php artisan db:seed
php artisan storage:link
chmod o+w -R storage bootstrap/cache public
```
